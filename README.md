# 3D Viewer v1.6.0

Visualiseur 3D web (FBX / glTF / ZIP) — menu style macOS.

**Créé** : 19 août 2026 · **MAJ** : 20 août 2026  
[chorfa.fr](https://chorfa.fr) · webmaster@chorfa.fr

## Fonctionnalités
- Menu horizontal : Fichier, Vue, Matériaux, Paramètres, Aide, À propos
- Chargement FBX / GLB / GLTF / ZIP
- Éditeur de matériaux avec **sélection** du matériau
- Lumières (Ambient, Directional, Point, Spot)
- Wireframe, cadrage, auto-scale, HUD

## Lancer
```bash
python3 -m http.server 8080
```
